# onface — 얼굴 특징점 기반 얼굴 비율 · 퍼스널 컬러 분석 iOS 앱

> 개인 프로젝트 · 2023 · 기획부터 데이터 제작, 모델 학습, 앱 개발까지 혼자 진행

사진 한 장으로 얼굴 비율을 분석하고, 피부 톤으로 퍼스널 컬러와 어울리는 향수 계열을 추천하는 iOS 앱입니다.
특징점 예측 모델을 **직접 라벨링한 데이터로 학습**하고, **TensorFlow Lite로 변환해 서버 없이 기기 안에서 추론**합니다.

## 주요 기능

- **얼굴 비율 분석**: 얼굴형, 중안부, 눈과 미간 너비, 눈 세로·가로폭, 눈과 눈썹 사이 거리, 미간·코·입 너비, 눈과 입의 위치, 입술 두께
- **퍼스널 컬러**: HSV 색공간에서 피부 채도·명도를 분석해 8가지 톤(봄 라이트·비비드, 여름 브라이트·뮤트, 가을 뮤트·딥, 겨울 브라이트·딥) 판별
- **향수 추천**: 톤과 얼굴 인상(직선형·곡선형)에 맞춰 woody, floral, fresh 등 향 계열 추천

## 처리 흐름

```
사진 입력
  → Haar Cascade로 얼굴 검출 (OpenCV)
  → 얼굴 영역 크롭 → 150×150 리사이즈 → RGB 정규화
  → MobileNet 기반 TFLite 모델 추론 → 특징점 49개 (x, y) = 98개 좌표
  → 좌표로 얼굴 비율 계산 / 피부 영역 HSV 분석
  → 결과 화면
```

## 모델

| 항목 | 내용 |
|---|---|
| 데이터 | 얼굴 이미지 **1,000장**에 특징점을 직접 라벨링, 이미지별 픽셀 좌표 파일 제작 |
| 모델 | MobileNet 기반 좌표 회귀 모델 (출력 98개 값) |
| 학습 | Python, TensorFlow |
| 배포 | TensorFlow Lite로 변환해 앱에 포함, 기기 안에서 추론 |

**온디바이스로 만든 이유**: 서버 없이 바로 결과를 보여줄 수 있고, 얼굴 사진을 외부로 전송하지 않아도 됩니다.

## 구현 포인트

- **OpenCV(C++) ↔ Swift 연결**: OpenCV는 C++ 라이브러리라 Objective-C++ 래퍼(`OpenCVWrapper.mm`)를 만들고 브리징 헤더로 Swift에서 호출
- **비율 계산 모듈**(`CalculatePoints.mm`): 예측 좌표로 얼굴 각 부위의 거리·비율·곡선 정도를 계산
- **배운 점**: 라벨링 기준이 조금만 흔들려도 예측이 흔들려서, 입력 데이터와 정답 좌표의 일관성이 모델 성능에 가장 중요하다는 것을 체감했습니다.

## 기술 스택

Swift · Objective-C++ · OpenCV · TensorFlow · TensorFlow Lite · MobileNet · Python
